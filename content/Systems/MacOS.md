# MacOS

## Fix for OneDrive on MacOs Catalina (10.15.x)

- [Fix for OneDrive on MacOs Catalina (10.15.x)](https://answers.microsoft.com/en-us/msoffice/forum/all/my-fix-for-onedrive-on-macos-catalina-1015x/de6ab37d-fa23-42b5-b5df-fbf05e09887b?page=18)

A. For those who have not implemented a previous fix, there might be nothing to reverse, in that case, simply download and install the insider preview version of OneDrive for MacOS 23.081 or later, found here: [https://oneclient.sfx.ms/Mac/Installers/23.081.0416.0001/universal/OneDrive.pkg](https://oneclient.sfx.ms/Mac/Installers/23.081.0416.0001/universal/OneDrive.pkg "oneclient.sfx.ms") 

In case the link shifts later, it can also be found in Hans Brender's blog, here: [All OneDrive Versions – Hans Brender's Blog](https://hansbrender.com/all-onedrive-versions/ "hansbrender.com")

As of the time of this update, DO NOT install OneDrive from the App Store, it still has the older non-working version (23.076). That is because the working versions (23.081 and later) are still "insider preview" versions.
